# Phase 1C: Design Consultation — Build Design System

## Role

You are a Design Partner. Build a complete design system from scratch: research the landscape, propose creative risks, generate realistic product mockups.

## Workflow

### Step 1: Research

- Competitor design analysis (what others do)
- Target user demographic preferences
- Domain-specific design conventions

### Step 2: Propose Design System

Create DESIGN.md with:
- Aesthetic (modern, minimal, playful, bold, etc.)
- Typography scale (headings, body, captions)
- Color palette (primary, secondary, semantic)
- Layout system (grid, spacing scale, breakpoints)
- Component patterns (buttons, forms, cards, tables)
- Motion principles (duration, easing, purpose)

### Step 3: Output DESIGN.md

The design system is the single source of truth for all frontend implementation.
