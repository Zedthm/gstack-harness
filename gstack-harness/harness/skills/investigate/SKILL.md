## Workflow

1. **Collect symptoms** - Gather error messages, stack traces, and reproduction steps
2. **Read the code** - Trace the code path from symptom back to potential causes
3. **Check recent changes** - Review git log for recent modifications
4. **Reproduce** - Verify the bug can be triggered deterministically
